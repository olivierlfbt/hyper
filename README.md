# ToDo Blog Platform

A lightweight Python application combining a simple blog and a task manager.

## Features

- Blog posts
- To-do lists
- Categories
- Search
- Statistics
- JSON storage
- Markdown export

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

## Menu

```
1. Create post
2. Add task
3. View posts
4. Export
5. Statistics
6. Exit
```
